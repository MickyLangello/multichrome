# Мультипрофильный лаунчер Google Chrome

Сценарий для интерактивного управления и запуска изолированных профилей Google Chrome. Поддерживает разделение пользовательских данных, сохранение индивидуального режима отображения (стандартное окно с вкладками или режим приложения без интерфейса браузера) и фиксацию времени последнего запуска каждого профиля.

Реализован в двух версиях:
- Bash-скрипт (`.sh`) — для операционных систем на базе Linux и macOS.
- PowerShell-скрипт (`.ps1`) — для Windows 10/11.

## Требования
- **Linux / macOS:** интерпретатор Bash, установленный Google Chrome или Chromium.
- **Windows:** PowerShell версии 5.1 или выше, установленный Google Chrome.

## Настройка директории профилей
По умолчанию папки профилей сохраняются по следующим путям:
- В Linux / macOS: `~/ChromeProfiles`
- В Windows: `С:\ChromeProfiles`

При необходимости изменить этот путь, отредактируйте переменную в начале соответствующего скрипта:
- В `.sh` файле: `BASE_PROFILE_DIR="/новый/путь"`
- В `.ps1` файле: `$BaseProfileDir = "C:\новый\путь"`

## Использование

### Linux / macOS (Bash)
1. Назначьте права на исполнение файла:
   ```bash
   chmod +x multichrome.sh
   ```
2. Запустите скрипт:
   ```bash
   ./multichrome.sh
   ```

### Windows (PowerShell)

> Перед первым запуском необходимо разблокировать файл сценария средствами операционной системы. Для этого нажмите правой кнопкой мыши по файлу `multichrome.ps1`, выберите пункт «Свойства», на вкладке «Общие» установите флажок «Разблокировать» внизу окна и нажмите «Применить».

Запустите скрипт через контекстное меню проводника «Выполнить с помощью PowerShell» или из консоли:
```powershell
.\multichrome.ps1
```

## Описание интерфейса и логики работы
- **Выбор сайта:** скрипт предлагает список предустановленных адресов. Нажатие клавиши `Enter` без ввода номера автоматически выбирает первый пункт меню.
- **Выбор профиля:** выводится список существующих профилей. Зеленым цветом выделены профили, настроенные на запуск в режиме приложения, желтым — в обычном режиме. Также доступно создание нового профиля.
- **Действия с профилем:** перед непосредственным запуском можно изменить режим отображения. При старте обновляется служебный файл `launch_mode.txt` в папке профиля, фиксируя текущие параметры и точное время запуска.

## Кастомизация списка сайтов
Для изменения предустановленных ресурсов отредактируйте массивы названий и адресов в теле выбранного скрипта. Количество элементов в обоих массивах должно совпадать.
